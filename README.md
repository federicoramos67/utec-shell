# utec-shell

Shell scripting basics for the UTEC intranet: navigation, file manipulation, and permissions.

## io_redirections_and_filters

Proyecto **Shell, redirecciones de entrada/salida y filtros**: scripts de Bash que practican redireccion de entrada/salida, tuberias y comandos de filtrado (head, tail, find, wc, sort, uniq, grep, tr, rev, cut).

| Archivo | Descripcion |
|---|---|
| 0-hello_world | Imprime "Hello, World" en la salida estandar. |
| 1-confused_smiley | Imprime el emoticono confundido "(Ôo)'. |
| 2-hellofile | Muestra el contenido de /etc/passwd. |
| 3-twofiles | Muestra el contenido de /etc/passwd y /etc/hosts. |
| 4-lastlines | Muestra las ultimas 10 lineas de /etc/passwd. |
| 5-firstlines | Muestra las primeras 10 lineas de /etc/passwd. |
| 6-third_line | Muestra la tercera linea del archivo iacta. |
| 7-file | Crea un archivo con nombre especial que contiene el texto "Best School". |
| 8-cwd_state | Guarda el resultado de ls -la en ls_cwd_content. |
| 9-duplicate_last_line | Duplica la ultima linea del archivo iacta. |
| 10-no_more_js | Elimina archivos regulares .js recursivamente. |
| 11-directories | Cuenta directorios y subdirectorios, incluidos ocultos. |
| 12-newest_files | Muestra los 10 archivos mas recientes, del mas nuevo al mas antiguo. |
| 13-unique | Imprime, ordenadas, las palabras que aparecen exactamente una vez. |
| 14-findthatword | Lineas de /etc/passwd que contienen "root". |
